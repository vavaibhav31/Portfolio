## Run locally

Clone the repo and open `index.html` in any browser:

```bash
git clone https://github.com/vavaibhav31/Portfolio.git
cd Portfolio
# then just open index.html
```

## Deploy (GitHub Pages)

This repo is already at `github.com/vavaibhav31/Portfolio`. To publish it:

1. Upload `index.html` and `Vaibhav_Agrawal_Resume.pdf` to the repository root.
2. Go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/ (root)**, then **Save**.
5. Wait ~1 minute. Your site goes live at **https://vavaibhav31.github.io/Portfolio/**.

That link is public and can be opened directly by anyone — add it to your résumé and LinkedIn.
