Open source · Python

MiniMe — an AI desktop companion

A desktop creature that lives on your screen, gets tired, sleeps at night and occasionally has a thought. My side project on how software should feel, not just what it computes.

PythonPySide6Simulation engineLocal LLM
190
passing tests
ReadClose
The idea
Every AI assistant lives inside a browser tab you have to go find. I wanted the opposite: a companion that's simply there, in your peripheral vision. Not an assistant — a simulated creature that only uses a language model to phrase thoughts it has already decided to have. It never opens a chat window.
What I built
  • A zero-dependency simulation engine in pure Python — importable, testable and runnable headless. PySide6 is used only for the desktop overlay.
  • Needs, mood and behaviour on a fixed tick loop, with sleep driven by a real two-process circadian model — the bedtime emerges from one constant rather than being hard-coded.
  • Five characters drawn procedurally in code (no image assets), so the whole repo is MIT-licensed and self-contained.
  • 190 tests and GitHub Actions CI that builds a one-file Windows executable on release.
Why it's here
Most of my work is analysis. This is the project where I had to be the one deciding what to build and holding it to an engineering standard — architecture, tests, delivery — end to end.
